# 오피스마스터 홈페이지

복사기·프린터 렌탈, 판매, 유지보수와 잉크·토너 서비스를 소개하는 홈페이지입니다.

## 파일 구성

- `index.html`: 소개 문구, 기기 목록, 주소와 연락처
- `style.css`: 데스크톱·모바일 디자인
- `app.js`: 메뉴, 기기 필터, 사진 확대와 연락처 복사
- `assets/`: 로고, 제품 사진과 브랜드 이미지

## GitHub Pages

저장소 Settings → Pages에서 Source를 **Deploy from a branch**, Branch를 **main**, 폴더를 **/(root)**로 설정합니다.

배포 주소: https://wakeahn.github.io/officemaster_landingpage/

별도 설치나 빌드 과정이 필요하지 않습니다. 변경 사항을 main 브랜치에 올리면 Pages 설정에 따라 반영됩니다.

## 로컬 미리보기

```sh
python3 -m http.server 4173
```

브라우저에서 http://localhost:4173 을 엽니다.

## 이미지 안내

브랜드용 인물·공간 이미지는 AI로 제작한 콘셉트 이미지이며 실제 임직원이나 고객의 기록 사진이 아닙니다. 기기 사진은 제조사 제품 자료입니다. 선택 안내용 참고 기종의 취급 여부는 상담으로 확인합니다.
